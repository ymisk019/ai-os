# 🔥 Yazan OS 3.0 — Fire Edition (الإصدار الناري)

نظام تشغيل حقيقي 64-bit مكتوب ومبني من الصفر، يجمع في تصميمه الرسومي وقوته بين **جمال وبساطة Windows 11، وأناقة شريط macOS، وانسيابية Android، واستقرار وقوة Linux**.

---

## 🌟 أبرز مميزات الإصدار 3.0

### 1. 🚀 شاشة تشغيل فخمة (Boot Splash Screen)
- شاشة إقلاع داكنة مع شعار **Yazan OS** المضيء بالأزرق الملكي.
- شريط تحميل متقدم (Progress Bar) يوضح مراحل الإقلاع:
  1. التحقق من سلامة المعالج (CPUID / Long Mode).
  2. فحص ذاكرة النظام (RAM Check) ومطابقتها للمتطلبات الدنيا (64MB).
  3. تفعيل وإعداد برامج قيادة الإدخال (PS/2 Keyboard & Mouse).
  4. تهيئة محرك الرسوميات وثنائي التخزين المؤقت (Double Buffering).
  5. تشغيل مدير النوافذ وسطح المكتب.

---

### 2. 🚨 الشاشة الحمراء لتشخيص الأخطاء (Red Screen of Death - RSOD)
- في حال وجود خطأ في العتاد، أو **نقص في الذاكرة العشوائية (RAM < 64MB)**، أو حدوث استثناء معالج كـ Page Fault أو Invalid Opcode:
  - ينقلك النظام فوراً لشاشة حمراء فخمة وواضحة (RSOD).
  - رسالة خطأ باللغتين العربية والإنجليزية:
    `:( YAZAN OS - SYSTEM HALTED`
    `STOP CODE: INSUFFICIENT_SYSTEM_RAM (0x0000003E)`
    `Detected RAM: 32 MB | Required RAM: 64 MB Minimum`
  - تفريغ كامل لسجلات المعالج (Registers) وسلسلة الاستدعاءات (Call Stack Backtrace) وخطوات تصحيح الخطأ للمستخدم (مثل زيادة الرام في QEMU أو VirtualBox).

---

### 3. 🎨 سطح المكتب الهجين (Windows + macOS + Android + Linux)
- **الشريط العلوي (Top Status Bar - نمط macOS / Android):**
  - شعار يزن + اسم التطبيق النشط حالياً.
  - ساعة رقمية ذكية في المنتصف (`12:45 PM`).
  - مؤشر استهلاك الذاكرة في الوقت الفعلي (`RAM: 48M/256M`) وحالة النظام (`OK`).
- **شريط المهام وقائمة ابدأ (Taskbar & Start Menu - نمط Windows 11):**
  - شريط سفلي زجاجي شفاف (Translucent Glass Effect).
  - زر وقائمة **Yazan Start** بتصميم عصري يضم بطاقة المستخدم، شريط البحث، وقائمة البرامج وزر إعادة التشغيل وفحص الأمان.
  - علامات تبويب للنوافذ المفتوحة مع خط تمييز سفلي أزرق للنافذة النشطة.
- **أيقونات سطح المكتب (Desktop Icons):**
  - أيقونات ملونة مربعة بتصميم حديث وجميل (Terminal, Calculator, Files, Notepad, Settings, Task Manager).
- **تقنية Double Buffering لمنع الوميض:**
  - يتم رسم جميع العناصر والمؤشر في Back Buffer فائق السرعة، ثم نقله إلى الشاشة مباشرة لضمان تجربة سلسة جداً (60 FPS) بدون أي تقطيع أو وميض.
- **فأرة ولوحة مفاتيح حقيقية:**
  - مؤشر ماوس ناعم مع ظل حقيقي (Drop Shadow) يدعم السحب والنقر وتحديد النوافذ.

---

### 4. 🪟 مدير النوافذ التفاعلي (Window Manager)
- نوافذ حقيقية تدعم:
  - **السحب والإفلات (Draggable)** من خلال شريط العنوان.
  - أزرار التحكم الحديثة (إغلاق أحمر، تكبير أخضر، تصغير برتقالي).
  - طبقات Z-order: النقر على أي نافذة يجعلها في المقدمة وفوق باقي النوافذ.

---

### 5. 📱 التطبيقات المدمجة والجاهزة
1. **الطرفية التفاعلية (Terminal `>_`):**
   - محاكي سطر أوامر مع موجه `yazan@os:~$ `.
   - أوامر تفاعلية: `help`, `info` (شعار الآسكي والمعلومات), `mem` (حالة الذاكرة), `clear`, `date`, `apps`, `panic` (تجربة الشاشة الحمراء), `reboot`.
2. **الآلة الحاسبة (Calculator `+-`):**
   - شاشة عرض رقمية وشبكة أزرار تفاعلية للعمليات الحسابية تدعم الفأرة ولوحة المفاتيح.
3. **مستعرض الملفات (File Explorer):**
   - استعراض ملفات النظام، المستندات، والبرامج مع تفاصيل الحجم والنوع.
4. **المفكرة ومحرر النصوص (Notepad):**
   - كتابة الملاحظات والنصوص وحذفها مع مؤشر كتابة نابض.
5. **معلومات النظام والإعدادات (System Settings & About):**
   - تفاصيل المعالج، الذاكرة، شريط بياني حي للرام، ومعلومات الإصدار.
6. **مراقب المهام والأداء (Task Manager):**
   - مراقبة النوافذ المفتوحة، العمليات النشطة، واستهلاك الذاكرة.

## 💻 إجابة السؤال المهم: شو لغة البرامج وكيف نعمل برنامج لنظام يزن؟

### 1. ما هي اللغة المستخدمة لكتابة برامج النظام؟
- **لغة C (C11 / GNU11):** هي اللغة الأم والأساسية لبرمجة نواة وتطبيقات نظام يزن حالياً (كما هو الحال في Windows و Linux و macOS). لغة C سريعة جداً، خفيفة، وتتعامل مباشرة مع الذاكرة والعتاد بدون وسيط.
- **لغة C++ (مستقبلاً):** يمكن كتابة تطبيقات كائنية التوجه (OOP) للنوافذ والأزرار.
- **لغات سكريبت (مثل Lua أو MicroPython):** يمكن تضمين مفسر صغير داخل نظام يزن لتشغيل سكربتات خفيفة بدون الحاجة لإعادة ترجمة النواة.

---

### 2. كيف تصنع برنامجاً جديداً لنظام يزن؟ (مثال عملي خطوة بخطوة)

تم وضع مثال تطبيقي متكامل في المجلد: `tools/sdk_example_app.c`.

لبناء أي برنامج في نظام يزن تحتاج 3 دوال أساسية فقط:

```c
#include "gui/wm.h"
#include "kernel/gfx.h"
#include "kernel/theme.h"

// 1. دالة الرسم (on_paint): يتم استدعاؤها لرسم واجهة تطبيقك
void my_app_paint(window_t *win, int cx, int cy, int cw, int ch) {
    gfx_fill_rect(cx, cy, cw, ch, 0x0F172A); // خلفية كحلية
    gfx_text(cx + 20, cy + 20, "مرحباً بكم في تطبيقي على Yazan OS!", 1, COL_TEXT_LIGHT);
    gfx_fill_rrect(cx + 20, cy + 50, 100, 30, 6, 0x2563EB); // زر أزرق
    gfx_text(cx + 35, cy + 60, "انقر هنا", 1, 0xFFFFFF);
}

// 2. دالة الفأرة (on_mouse): التعامل مع نقرات المستخدم
void my_app_mouse(window_t *win, int rx, int ry, int btns, int clicked) {
    if (clicked && rx >= 20 && rx <= 120 && ry >= 50 && ry <= 80) {
        // قام المستخدم بالنقر على الزر!
    }
}

// 3. دالة لوحة المفاتيح (on_key): استقبال الأحرف
void my_app_key(window_t *win, char key) {
    // معالجة الحرف المضغوط
}

// 4. دالة تشغيل التطبيق وفتح نافذته:
window_t *my_app_open(void) {
    // إنشاء نافذة بعرض 400 وارتفاع 300
    window_t *win = wm_create_window("تطبيقي الجديد", 100, 100, 400, 300, ICON_TERMINAL);
    win->on_paint = my_app_paint;
    win->on_mouse = my_app_mouse;
    win->on_key   = my_app_key;
    return win;
}
```

ببساطة شديدة: تسجل تطبيقك في مدير النوافذ (`wm_create_window`)، وتحدد أبعاد النافذة، ثم تتولى دوال الرسم والنقر الباقي تلقائياً!

## 🛠️ أوامر البناء والتشغيل

```bash
# 1. بناء ملف النواة ELF
make

# 2. بناء ملف الـ ISO القابل للإقلاع
make iso

# 3. تشغيل النظام على محاكي QEMU مع 256MB رام
make run

# 4. تشغيل تجربة الشاشة الحمراء (نقص الرام - 32MB) لإظهار رسالة الخطأ
make run-lowram

# 5. توليد صور المعاينة عالية الدقة (PPM و PNG) لسطح المكتب والشاشات
make preview
```

### صور المعاينة المتاحة بعد التشغيل:
- `build/preview-boot.png`: شاشة الإقلاع الفخمة مع شريط التحميل.
- `build/preview-desktop.png`: سطح المكتب وتطبيقا الطرفية والآلة الحاسبة.
- `build/preview-startmenu.png`: قائمة ابدأ وشريط المهام.
- `build/preview-panic-ram.png`: الشاشة الحمراء عند نقص الرام عن 64MB.
- `build/preview-panic-fault.png`: الشاشة الحمراء مع سجلات المعالج عند حدوث استثناء.
